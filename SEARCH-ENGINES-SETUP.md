# Настройка поисковых систем для IT-WO

## Google Search Console

### 1. Добавление сайта
1. Перейдите на https://search.google.com/search-console
2. Нажмите "Добавить ресурс"
3. Выберите "Префикс URL" и введите `https://it-wo.ru`
4. Подтвердите владение (рекомендуется через HTML-тег)

### 2. Подтверждение через HTML-тег
Добавьте в `src/components/BaseHead.astro`:
```html
<meta name="google-site-verification" content="YOUR_CODE_HERE" />
```

### 3. Отправка sitemap
1. В Search Console перейдите в "Карты сайта"
2. Добавьте URL: `https://it-wo.ru/sitemap-index.xml`
3. Нажмите "Отправить"

### 4. Мониторинг
- **Производительность**: отслеживайте клики и показы
- **Покрытие**: проверяйте индексацию страниц
- **Core Web Vitals**: мониторьте метрики
- **Удобство использования**: проверяйте мобильную версию

## Yandex.Webmaster

### 1. Добавление сайта
1. Перейдите на https://webmaster.yandex.ru
2. Нажмите "Добавить сайт"
3. Введите `https://it-wo.ru`
4. Подтвердите владение (рекомендуется через HTML-тег)

### 2. Подтверждение через HTML-тег
Добавьте в `src/components/BaseHead.astro`:
```html
<meta name="yandex-verification" content="YOUR_CODE_HERE" />
```

### 3. Отправка sitemap
1. В Вебмастере перейдите в "Индексирование" → "Файлы Sitemap"
2. Добавьте URL: `https://it-wo.ru/sitemap-index.xml`
3. Нажмите "Добавить"

### 4. Настройка
- **Главное зеркало**: установите `https://it-wo.ru` (с www или без)
- **Региональность**: Россия
- **Переобход страниц**: включите автоматический переобход

### 5. Мониторинг
- **Индексирование**: проверяйте количество проиндексированных страниц
- **Поисковые запросы**: анализируйте популярные запросы
- **Качество сайта**: следите за ИКС (Индекс Качества Сайта)
- **Безопасность**: проверяйте на вирусы и взломы
